# MVP仕様

AlgoHint Coach は、ローカルまたはColab上で個人が使うPythonアルゴリズム演習アプリです。問題選択、提出、判定、段階的ヒント、解説、学習レポートをGradioで提供します。

正誤はLLMではなくLocalJudgeの決定的なテスト実行で判定します。解説はACまたはギブアップ後にだけ表示し、模範コードは教師モードに限定します。

| 判定 | 意味 |
|---|---|
| AC | 全テストの出力が一致した |
| WA | 実行できたが出力が一致しない |
| RE | 実行中に例外または異常終了した |
| TLE | テストごとの実行制限を超えた |
| CE | 構文などのコンパイル段階のエラー |
| IE | Judge側の予期しない問題 |

ローカル実行を再現するDocker／Dev Container環境はMVPに含みます。提出ごとの強固なコンテナ隔離、公開運用、ユーザー認証、外部OJ提出、外部LLM接続、Flet UIはMVPの対象外です。
