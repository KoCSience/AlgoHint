# MVP仕様

AlgoHint Coach は、ローカルまたはColab上で個人が使うPythonアルゴリズム演習アプリです。問題選択、提出、判定、段階的ヒント、解説、学習レポートをGradioで提供します。

正誤はLLMではなくLocalJudgeの決定的なテスト実行で判定します。解説はACまたはギブアップ後にだけ表示し、模範コードは教師モードに限定します。

| 判定 | 意味 |
|---|---|
| AC | 全テストの出力が一致した |
| WA | 実行できたが出力が一致しない |
| RE | 実行中に例外または異常終了した |
| TLE | テストごとの実行制限を超えた |
| CE | 構文などのコンパイル段階のエラー |
| IE | Judge側の予期しない問題 |

ローカル実行を再現するDocker／Dev Container環境はMVPに含みます。提出ごとの強固なコンテナ隔離、公開運用、ユーザー認証、外部OJ提出、Flet UIはMVPの対象外です。

## 適応型ヒント拡張

外部LLMは、LocalJudgeを置き換えずヒントだけを個別化します。プロフィールごとに
GPT-5.6、Gemma 4 12B、Geminiを選択でき、接続できない場合はRuleBasedヒントへ
退避します。クラウドへ送る情報と保存範囲は
[適応型ヒントとLLM設計](llm-hint-design.md)で定義します。

問題演習画面にはコード実行、エラー診断、質問、「わからない」、ヒント履歴、解説を
まとめます。プロフィール選択とモデル選択は共通ツールバーへ配置します。
