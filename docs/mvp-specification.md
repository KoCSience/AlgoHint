# MVP仕様

AlgoHint Coach は、ローカルまたはColab上で個人が使うPythonアルゴリズム演習アプリです。
問題選択、提出、判定、段階的ヒント、完了後の復習、学習レポートをGradioで提供します。

正誤はLLMではなくLocalJudgeの決定的なテスト実行で判定します。解説、復習小テスト、
コード改善レビューは、全テストACまたはギブアップ後にだけ表示します。模範コードは
教師モードに限定します。公開サンプルだけのACは、問題完了として扱いません。

| 判定 | 意味 |
|---|---|
| AC | 全テストの出力が一致した |
| WA | 実行できたが出力が一致しない |
| RE | 実行中に例外または異常終了した |
| TLE | テストごとの実行制限を超えた |
| CE | 構文などのコンパイル段階のエラー |
| IE | Judge側の予期しない問題 |

ローカル実行を再現するDocker／Dev Container環境はMVPに含みます。提出ごとの強固なコンテナ隔離、公開運用、ユーザー認証、外部OJ提出、Flet UIはMVPの対象外です。

## 問題選択と起動時の復元

プロフィールの `last_problem_id` は「次に画面を開くとき、どの問題へ戻るか」を表す
利便性の状態です。これは学習成果、進捗、完了、解禁条件を表す状態ではありません。

- 選択中の問題を問題文と同時に表示し、セレクターだけが選択済みになる不整合を作らない。
- 保存値が現行カリキュラムに存在すれば、その問題を復元する。
- 初回または保存値なしでは、カリキュラム順で最初のL0を選択・表示する。
- 保存値が削除・改名済みなら最初のL0へ戻し、`last_problem_id` も自己修復する。
- 問題が一件もなければ未選択状態を明示し、架空のIDを保存しない。
- 保存に失敗しても現在の問題は利用可能にし、「次回用の選択だけ保存できなかった」と
  区別して通知する。

複数タブから変更した場合は、最後に保存された有効な選択が次回の復元対象になります。
どのタブを正とする競合解決は行いません。完了判定は必ずプロフィール別学習ログの
`ProblemProgress.solved` / `gave_up` を使い、`last_problem_id` を認可や解禁に使いません。

## 適応型ヒント拡張

外部LLMは、LocalJudgeを置き換えずヒントだけを個別化します。プロフィールごとに
GPT-5.6、Gemma 4 12B、Geminiを選択でき、接続できない場合はRuleBasedヒントへ
退避します。クラウドへ送る情報と保存範囲は
[適応型ヒントとLLM設計](llm-hint-design.md)で定義します。

問題演習画面にはコード実行、エラー診断、質問、「わからない」、ヒント履歴をまとめます。
解説と小テスト、AIレビューは完了専用タブへ分離します。プロフィール選択、モデル選択、
AI小テスト問題数は共通ツールバーへ配置します。

質問欄はEnterで改行し、Ctrl+Enter（macOSはCmd+Enter）で送信します。質問、
「わからない」、「実行結果からヒント」は、回答を待たず検証済みのユーザーメッセージを
ブラウザ上の会話へ直ちに追加します。生成に失敗または中断した質問は暫定表示を除去し、
永続履歴に片側だけ残しません。

生成中の秒数は完了予測ではなく、要求開始からの実測経過時間です。完了後は実測所要時間を
表示します。モデル、混雑、ネットワークで所要時間が変動するため、残り時間や完了予定時刻は
表示しません。

## 完了後の復習

全テストACまたは初回ギブアップ後に完了専用タブを解禁し、固定5問を表示します。
固定5問すべてを初めて採点した時点で、得点にかかわらず解説とAIレビューのロックを
恒久解除します。解除後も本文は自動表示せず、それぞれのボタンを押した場合だけ表示します。

1. アルゴリズム、問題の捉え方、計算量、境界条件、実装注意を各一問含む固定5問
2. 採点後に任意表示する教材解説
3. 保存済みAIレビューの任意表示と、現在コードに対する新規AIレビュー
4. 全テストAC済みコードから生成する任意のAI小テスト

小テストは教材ファイルの安定した問題ID・選択肢IDで決定的に採点します。採点前の
学習者向けDTOには正解IDと正解解説を含めません。採点後は各問について選択内容、
正解、解説を表示し、その時点の問題文・選択肢・正解・解説のスナップショットを履歴へ
保存します。教材の後日変更で過去履歴の意味が変わらないための設計です。

AI小テストは全テストAC時だけ生成し、ギブアップでは生成しません。初回ACの結果と固定5問を
先に表示し、同意済みなら現在コードから既定2〜5問（設定で3問固定）を非同期生成します。
生成済みでも固定5問の初回採点前は公開しません。採点は保存済み正答で決定的に行い、
生成失敗や未同意でも固定5問、解説、レビューの利用を妨げません。

AIコード改善レビューは、アルゴリズムの要約、良い点、正確性・境界条件・計算量・
可読性・保守性の優先改善点を構造化して返します。完成コードや置換コードは生成せず、
提出コードの長い行をそのまま再掲する応答も拒否します。クラウドまたはリモートGemmaへ
送る場合は、ヒントと共通のブラウザセッション同意を要求します。生成失敗時は固定解説と
小テストを利用可能なままにし、別プロバイダへ自動転送しません。

固定・AI小テストとコード改善レビューの履歴は、プロフィールごとのSQLiteへ新しい順に保存し、
各画面では20件単位で表示します。提出ソースそのものは保存しません。論理JSONサイズの
合計はプロフィールごとに1 GiBを上限とし、80%から警告、超過時は履歴種別を問わず
最古のレコードから同一トランザクション内で整理します。
