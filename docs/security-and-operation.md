# 安全な運用

LocalJudgeは `shell=False`、一時ディレクトリ、`python -I`、タイムアウト、出力上限、POSIX環境でのCPU・メモリ上限を用います。これは学習時の事故を減らすための対策であり、悪意あるコードを完全に隔離するサンドボックスではありません。

そのため、アプリは単一PCまたは信頼できる個人のColabセッションでだけ使ってください。`--share` は明示的に指定した場合だけ有効ですが、不特定多数への公開には使えません。公開運用が必要になった場合は、ネットワーク遮断を含むDocker隔離、認証、資源監視、監査ログを別途実装します。

学習ログはプロフィール名、提出回数、ヒント数、判定、完了状態だけを保存します。提出したソースコードやAPIキーは保存しません。`data/runtime/` はGit管理しません。

隠しテストは通常UIに表示しませんが、ローカルリポジトリを閲覧できる利用者から物理的に隠せるものではありません。
