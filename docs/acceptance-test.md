## 問題選択と質問UI

- [ ] 初回起動で最初のL0がセレクターに選ばれ、同じL0の見出し・問題文・公開サンプルが表示される。
- [ ] 問題を変更して再起動またはプロフィールを再選択すると、同じプロフィールの最後の有効な問題が選択・表示される。
- [ ] 別プロフィールには、そのプロフィール自身の最後の問題または既定L0が表示される。
- [ ] `last_problem_id` の問題が教材から消えている場合、既定L0を表示して保存値も修復する。
- [ ] 問題選択状態だけでは、解説、小テスト、コードレビュー、学習レポート上の完了が解禁されない。
- [ ] 問題選択の保存が失敗しても現在問題を閲覧・提出でき、次回用状態だけの警告になる。
- [ ] 複数タブで異なる問題を選ぶと最後に保存された有効な選択が次回復元され、学習進捗は失われない。
- [ ] モデル設定を変更しても `last_problem_id` が保持され、問題を変更してもモデル設定が保持される。
- [ ] 質問欄のEnterは改行となり、Ctrl+Enter（macOSはCmd+Enter）は「質問する」と同じ一回の要求になる。
- [ ] 有効な質問は回答前に会話欄へ表示され、入力欄がクリアされる。
- [ ] 同意不足・入力不正・生成失敗時は質問を再入力でき、永続履歴に回答なしの質問が残らない。
- [ ] 生成中表示は実測の「経過時間」であり、`s / s`形式や完了予測を表示しない。
- [ ] 完了後に実測の「所要時間」が表示され、Gradio既定の進捗時間は非表示である。

## 完了後の復習

- [ ] 公開サンプルACだけでは解説、小テスト、AIコードレビューが解禁されない。
- [ ] 全テストACまたはギブアップ後に、解説と選択式小テスト5問が表示される。
- [ ] 5問はアルゴリズム、問題の捉え方、計算量、境界条件、実装注意を一問ずつ含む。
- [ ] 5問すべてを選ぶまで採点せず、存在しない選択肢IDを拒否する。
- [ ] 採点前のUI/APIに正解IDと正解解説が含まれず、採点後に各問の回答・正解・解説が表示される。
- [ ] 小テスト再回答が新しい履歴として残り、20件を超えると新しい／古い履歴へ移動できる。
- [ ] 全テストACまたは初回ギブアップ時に現在コードのAIレビューを一回開始し、完了済み問題ではボタンから再試行できる。
- [ ] AIレビューにアルゴリズム要約、良い点、1〜5件の分類済み改善点が表示される。
- [ ] 完了前、コード空、16KiB超過、外部送信未同意ではプロバイダを呼ばず、安全な案内を表示する。
- [ ] コードレビュー要求に隠しテスト、模範解答、小テスト正解、プロフィール表示名が含まれない。
- [ ] 提出コードを再掲する応答、完成解答の疑いがある応答、不正JSONは保存・表示されない。
- [ ] AIレビュー失敗時も固定解説と小テストを利用でき、別クラウドへ自動転送されない。
- [ ] AIレビュー履歴は20件単位で移動でき、生成プロバイダ・モデル・日時が分かる。
- [ ] SQLite履歴には小テストの詳細と生成済みレビュー文が残り、提出ソース・プロンプト・キーは残らない。
- [ ] 履歴使用量がプロフィール単位で表示され、80%以降に警告する。
- [ ] 1 GiB超過時は小テスト・レビューを横断して最古から整理し、他プロフィールには影響しない。
- [ ] 同時保存でも履歴を失わず、上限計算と削除が一つのトランザクションで完了する。
- [ ] 教材・モデル出力のHTML特殊文字が実行可能なHTMLとして表示されない。
